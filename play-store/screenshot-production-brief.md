# Arrow Escape: Puzzle Maze — Play Store Screenshot Production Brief

Goal: replace generic screenshots with a conversion-focused set that shows real gameplay and the strongest current features. Use the actual release build/UI. Do not show features or rewards that are not present in the app.

## Visual direction

- Portrait phone screenshots.
- Keep the current dark navy/cyan/purple premium visual identity.
- Use large, short headlines that remain readable at Play Store thumbnail size.
- Keep important UI away from the extreme top/bottom crop areas.
- Prefer real in-game screens over mock UI.
- Each frame should communicate one benefit in under 2 seconds.

## Recommended 8-frame sequence

### 1. Core gameplay hero
Headline: **THINK. TAP. ESCAPE.**
Subline: **Untangle arrows in the right order**
Capture: a visually dense but readable mid-game puzzle with several arrows still active.
Purpose: explain the game immediately.

### 2. Full-clearance mechanic
Headline: **PLAN THE FULL ESCAPE**
Subline: **Other arrows — and your own tail — can block the path**
Capture: gameplay state where one obvious-looking arrow is blocked and another is the correct move.
Purpose: show the puzzle depth and the distinctive clearance rule.

### 3. 200-level campaign
Headline: **200 PUZZLES TO MASTER**
Subline: **Harder chapters. Bigger challenges. Boss milestones.**
Capture: level-select screen showing chapter progression, stars and locked/unlocked levels.
Purpose: communicate content depth.

### 4. Daily Challenge
Headline: **A NEW DAILY CHALLENGE**
Subline: **Beat the super-hard puzzle and earn 200 coins**
Capture: Daily Challenge panel plus a real challenge puzzle if possible.
Purpose: show a strong retention feature.

### 5. Rewards and streaks
Headline: **PLAY. RETURN. EARN.**
Subline: **Daily streak rewards grow up to 75 coins**
Capture: Daily Streak screen showing the reward ladder.
Purpose: highlight progression without implying real-money value.

### 6. Achievements
Headline: **TRACK YOUR PROGRESS**
Subline: **Stars, perfect clears, bosses and achievements**
Capture: Achievements screen with several progress cards.
Purpose: show longer-term goals.

### 7. Arrow styles and themes
Headline: **MAKE EVERY ESCAPE YOURS**
Subline: **Unlock arrow styles and board themes with coins**
Capture: Store with Arrow Garage or Themes visible.
Purpose: showcase customization.

### 8. Help when needed
Headline: **STUCK? GET A HINT**
Subline: **Use hints, revives and optional rewarded ads**
Capture: active level with hint/assist controls visible, or Store/coin reward screen.
Purpose: reassure new players that difficult levels remain approachable.

## Capture checklist

- Use the latest release candidate, not an old tester build.
- Hide debug labels and test-ad indicators.
- Do not use personally identifying notifications, status-bar content or unrelated overlays.
- Keep coin/reward values consistent with the current production economy.
- Verify Daily Challenge shows the production 200-coin reward.
- Verify all screenshots use current arrow visuals and current home/store/settings layouts.
- Use clean game states; avoid failure dialogs unless the frame specifically explains a feature.
- Review every final image at small thumbnail size before Play Console upload.

## Store copy pairing

The screenshot sequence should visually reinforce the current Play Store listing themes: arrow logic puzzle gameplay, 200 levels, Daily Challenge, rewards/streaks, achievements, customization, tutorial/help and offline core play.
